正式邮件和微信聊天是两种不同的沟通方式。微信追求即时和碎片化，邮件追求完整和可追溯。很多同学第一次写正式邮件时不知道从哪下手，这里整理一套可以直接套用的模板。

## 邮件结构

一封标准的正式邮件包含六个部分：主题、称呼、正文、附件、结尾、落款。

### 主题：清晰凝练

格式：`【类型】核心事件 - 关键信息`

示例：
```
【实习申请】前端开发实习生 - 张三 - XX大学
【周报】产品研发部 - 第三周工作汇报
【请假】关于5月20日参加毕业论文答辩的申请
```

主题要让收件人一眼就知道邮件的目的和优先级。

### 称呼：正式礼貌

顶格写称呼，另起一行开始正文。

```
尊敬的张经理：

您好！

（正文内容）
```

不确定对方职位时，用「老师」或「您好」开头比较稳妥。

### 正文：背景 + 核心问题 + 请求

结构清晰的三段式：

```
第一段：我是谁，为什么写这封邮件
第二段：具体事项，需要的信息或问题
第三段：希望对方做什么，截止时间
```

如果篇幅较长，用小标题分段，方便对方快速浏览。

### 附件：正文中标注

在正文中提示附件内容，确认附件格式正确（PDF 比 Word 更通用），文件名包含你的姓名和内容概要。

```
详见附件《张三-前端开发实习生简历-20260802.pdf》
```

### 结尾：期待 + 祝福

如需回复，表达期待，加上祝福语。

```
期待您的回复。
祝好！
```

### 落款：完整信息

```
张三
XX大学 计算机科学与技术学院
电话：138xxxxxxx
邮箱：zhangsan@xx.edu.cn
```

## 几个实用模板

### 模板一：实习申请

```
主题：【实习申请】前端开发实习生 - 张三

尊敬的招聘负责人：

您好！

我是 XX 大学计算机科学与技术学院 2024 级的张三，目前主修软件工程方向。了解到贵公司正在招聘前端开发实习生，特此提交申请。

在校期间，我完成了 HTML/CSS/JavaScript 基础课程，使用 React 开发过两个课程项目，熟悉 Git 工作流和基本的 Linux 操作。详见附件简历。

期待您的回复。
祝好！

张三
XX大学 计算机科学与技术学院
电话：138xxxxxxx
```

### 模板二：联系导师

```
主题：毕业论文选题咨询 - 张三 - 计算机学院

尊敬的张老师：

您好！

我是计算机学院 2024 级的学生张三，计划在网络安全方向做毕业设计，想请教您几个选题方向的问题。

我目前对 Web 安全测试和入侵检测两个方向比较感兴趣，但不确定哪个方向更适合作为本科毕设的深度。不知您近期是否有时间当面请教？

期待您的回复。
祝好！

张三
计算机科学与技术学院
电话：138xxxxxxx
```

## 常见错误

- 没有主题或主题模糊
- 称呼缺失或错误（把「老师」写成「老湿」）
- 正文不分段，一大段文字
- 附件忘记加或格式不对
- 不留联系方式或联系方式不完整
- 回复时不引用原文，对方不知道在说什么
- 语气过于随意（把「您好」写成「嗨」）

## 几个原则

- 一封邮件只讲一件事，方便对方转发和处理
- 需要对方做的事情放在开头或结尾显眼位置
- 截止时间明确写出来
- 发送前检查一遍收件人地址、附件、错别字
- 工作日发送，非紧急事项不要在周末或深夜发
